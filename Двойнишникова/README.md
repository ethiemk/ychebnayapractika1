# Жилой фонд и хранение данных

**Ответственный за модуль:** Двойнишникова.

## Зона ответственности

- общежития, комнаты, заселения и контроль вместимости;
- контекст Entity Framework Core и универсальный репозиторий;
- создание и обновление базы, миграции и SQL-скрипты;
- общие модели выдачи данных и ошибок валидации.

## Объём

- C#-файлов: **19**;
- строк C#-кода: **2549**.

Пути файлов сохранены относительно корня решения. Четыре модуля не содержат дублирующихся C#-файлов и вместе образуют полный исходный код приложения.

## Сборка после объединения

Объедините содержимое четырёх модулей в одном каталоге, затем выполните:

```powershell
dotnet restore "DormitoryPayments.slnx"
dotnet test "DormitoryPayments.slnx"
dotnet run --project "src\DormitoryPayments.WinForms\DormitoryPayments.WinForms.csproj"
```

Полный перечень переданных файлов приведён в `МАНИФЕСТ.md`.
